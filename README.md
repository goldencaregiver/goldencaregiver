### Ключевая экспертиза & Проекты
- **Distributed & Highload Services:** Проектирование высоконагруженных микросервисов на Go, работа с конкурентностью (goroutines, channels, sync primitives, context).
- **Network & Security Protocols:** Реализация защищенных сетевых взаимодействий (gRPC, TLS/SSL, JWT/OAuth2), профильный бэкграунд в анализе защищенности веб-приложений и сетей.
- **Speech-to-Text Processing Service:** Асинхронный сервис распознавания и обработки голосовых сообщений с интеграцией Telegram API (нагрузка 11k+ уникальных пользователей/читателей разбора).
- **CTF & Security Research:** 3-е место на M*CTF (команда «Синай») — специализация на Web, Crypto и Reverse Engineering.
- **R&D Publications:** Автор научных публикаций (РИНЦ) в сфере цифровой трансформации и безопасности информационных систем.
